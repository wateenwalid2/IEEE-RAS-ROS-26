## Notes
The difference between the main ROS concepts:
- **Node**: A node do a specific task, so that there are many nodes in a system as each node do one thing 
- **Topic**: A communication way provided by ROS to allow many nodes to communicate with each other, used for continuous data streams (no response expected)
- **Service**: An interface provided by ROS to allow many nodes to communicate with each other, used for an specific task needed (request & response communication)
